Respuesta al ejercicio 1.2

Caso de uso: Cliente consulta la ficha de un producto desde el buscador

  1. El cliente escribe el nombre de un producto en el buscador de la tienda y pulsa el botón "Buscar".
  2. El navegador realiza una petición https al servidor web incluyendo el texto de la búsqueda.
  3. El servidor web detecta el script de PHP que debe atender la petición, asi que encarga su ejecución al motor PHP.
  4. El motor PHP arranca e inicia la ejecución del script.
  5. El código del script contiene:
    • Código para la recepción y comprobación del texto de la búsqueda.
    • Código para la conexión con la base de datos.
    • Código para consultar productos que coinciden con la búsqueda.
    • Código para almacenar los datos obtenidos
    • Código para mostrar la respuesta obtenida al cliente generando al HTML correspondiente.
  6. Una vez obtenido el resultado, el HTML obtenido es enviado al servidor web como resultado de la ejecución.
  7. El servidor web recoge los datos enviados por el motor PHP y lo envía al navegador con una respuest HTTP.
  8. Finalmente, el navegador recibe la respuest HTTP y lo renderiza para mostrarlo al cliente.

Respuesta al ejercicio 1.3

Tecnología ¿Dónde y como se usaría en el contexto de los ejercicios 1.1 y 1.2?
HTTP Para proteger mediante cifrado esas comunicaciones, incluyendo las búsquedas, el inicio de sesión o el envío de datos de un pedido.
HTTPS Se usaría para establecer las conexiones seguras para la transmisión de información entre cliente y servidor.
HTML Se usaría para estructurar el formulario del buscador y la lista de resultatos con la información.
PHP Se usaría para recibir el texto de la búsqueda, comprobarlo, solicitar los productos a la base de datos y, por último, generar el HTML con los resultados.
CSS Se usaría para aplicar formato al HTML mostrado al cliente.
SQL Se utilizaría en este caso, para consultar el producto solicitado por el cliente y obtener la información de este..
JavaScript Por ejemplo, podría usarse para mostrar sugerencias mientras el usuario escribe en el buscador.
